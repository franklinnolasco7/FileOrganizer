# 📁 File Organizer Pro

**Professional file organization powered by Jeff Su's Framework for Windows.**

---

## ✨ Features

* **Automatic Organization** — Sort files by category
* **Jeff Su Framework** — Proven folder structure:
  `01_Personal`, `02_Work`, `03_Templates`, `04_Temp_Share`, `05_Archive`
* **Real-time Logging** — Live activity feedback
* **Modern UI** — Windows 11 Fluent Design
* **Persistent Settings** — Remembers your preferences

---

## ⚙️ Installation

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/file-organizer-pro.git
cd file-organizer-pro

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the app
python -m app
```

---

## 🚀 Usage

1. Select the **source folder**
2. Select the **destination folder**
3. Choose file **categories to organize**
4. Click **Organize**

Files will be automatically sorted into category folders based on file extensions.

---

## 📦 Requirements

* **Python** 3.9+
* **PyQt6** 6.7.0+
* **qfluentwidgets** 0.4.7+
